# 리스트 클론 코딩

## 입력

- 예시 이미지(FewShot): **$1**
- 리스트 목록: **$ARGUMENTS**
  - `$ARGUMENTS`에는 첫 번째 값(이미지 경로)도 같이 들어 있으므로, **첫 번째 값을 뺀 나머지**를 리스트 목록으로 사용한다.

## 작업 순서

### 1. 예시 이미지 분석

- `$1` 이미지를 열어서 아래 항목을 파악한다.
  - 배치: 가로/세로 방향, 줄 수, 항목 간격
  - 항목 모양: 글자만 있는지, 아이콘·이미지·구분선이 있는지
  - 스타일: 글자 크기·굵기·색, 배경색, hover나 선택된 항목 표시
- 이미지 파일을 찾을 수 없으면 경로를 다시 확인해 달라고 안내하고 멈춘다.

### 2. 리스트 목록 정리

- 리스트 목록을 쉼표나 줄바꿈 기준으로 나눠서 항목 하나씩 정리한다.
- 목록이 비어 있으면 이미지에 보이는 항목을 그대로 사용한다.

### 3. 코드 작성

- 이미지와 **같은 모양**으로, 항목만 2단계에서 정리한 리스트 목록으로 바꿔서 만든다.
- 프로젝트에서 이미 쓰는 기술과 폴더 구조, 코드 스타일을 따른다.
  - 예: Next.js + Tailwind 프로젝트면 `components/` 폴더에 컴포넌트로 만든다.
- 이미지에 없는 기능이나 디자인은 임의로 추가하지 않는다.

### 4. 결과 보고

- 만들거나 수정한 파일 경로를 보여준다.
- 이미지와 다르게 만든 부분이 있으면 무엇을 왜 다르게 했는지 알려준다.

## 사용 예시

```
/menu-clone ./images/menu.png 채소, 과일·견과·쌀, 수산·해산·건어물, 정육·가공육·계란
```
